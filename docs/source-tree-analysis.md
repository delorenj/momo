## Critical Directories

### `.` (repo root)

The product lives at the **root**, not in a `src/`. The three hand-authored files
(`BRAINDUMP.md`, `PILLARS.md`, `.project.json`) plus `mise.toml` are the entire meaningful
surface today.

**Purpose:** Vision, doctrine, project identity, and tooling entry point.
**Contains:** Markdown docs, pjangler `.project.json`, `mise.toml`.
**Entry Points:** `mise.toml` (all workflows start from `mise` tasks/hooks).

### `.mise/`

**Purpose:** Task runner scripts and versioning wiring — the operational backbone.
**Contains:** `link-agentfiles.sh`, `versioning.sh`, `version-files.conf`.
**Integration:** Invoked by `mise.toml` `[hooks].enter` and the `version:*` / `link-agentfiles` / `hindsight-setup` tasks.

### `_bmad/` (🔴 framework)

**Purpose:** BMAD Method v6.10.1 — planning & documentation workflows, shipped as skills.
**Contains:** `bmm/`, `core/`, `bmb/`, `cis/`, `custom/`, `scripts/` (incl.
`resolve_customization.py`, the workflow customization resolver).
**Integration:** Drives `/bmad-*` slash commands and the BMAD skills used to plan Momo.

### `.claude/` · `.agents/` · `.opencode/` · `.github/agents/` (🔴 framework)

**Purpose:** Multi-CLI agent/skill config fanned out from the 33GOD ecosystem SSOT.
**Contains:** ~63 `bmad-*` skill packages (duplicated across `.claude/skills` and
`.agents/skills`), OpenCode command routers, Copilot agent definitions.
**Integration:** These make BMAD workflows available across Claude Code, OpenCode, and
Copilot. **They are not part of Momo's implementation.**

## Entry Points

- **Main Entry:** `mise.toml` — the operational entry point. `mise enter` runs the enter
  hooks; `mise tasks` lists everything runnable.
- **Policy-client Entry:** `skill/scripts/lifecycle_client.py`; MCP and generic
  agent packaging remain future entry points.

## File Organization Patterns

- **Root-doc product model** — the "code" today is authored Markdown at the repo root, not
  a package under `src/`.
- **Dotfile scaffold** — nearly all machinery lives in dot-prefixed dirs (`.mise`,
  `.claude`, `.agents`, `.opencode`, `.github`, `.codegraph`, `_bmad`).
- **SSOT fan-out** — the same skill set is mirrored into multiple CLI-specific config trees
  rather than authored per-CLI.
- **Managed blocks** — `mise.toml` contains a `# >>> mise-versioning >>>` managed region
  (regenerated by the versioning skill; do not hand-edit).
